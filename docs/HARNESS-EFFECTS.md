## Canonical effect decision

DexThemes does not add arbitrary CSS or a broad speculative effect schema in this slice. It adds a narrow optional `dexthemes-effect-intent-v1` contract for safe preview and apply preparation: gradient, alpha, or blur over known canonical palette slots only. Intents have exact keys and numeric/enumerated bounds, a 2 KB ceiling, and mandatory solid, high-contrast, and reduced-motion fallbacks. The resolver enables only documented registry capabilities (currently Zed alpha/appearance and Cursor alpha); unsupported, unknown, or experimental effects are omitted with an explicit reason and a deterministic solid fallback.

This view model is not CSS and no current adapter applies these effects. Zed still requires a future delivered adapter before effect intents can reach its host theme format. Antigravity stays unknown and Grok Build's complete palette remains preview-only. The canonical solid palette remains authoritative.

The safety rules are fixed:

- no selectors, HTML, JavaScript, CSS functions, URLs, data URIs, images, filters, or executable expressions;
- no inference that `string` means gradient, shadow, or image support;
- no DOM injection or internal host selectors;
- solid fallback is mandatory;
- contrast is validated after any future alpha composition;
- motion stays off unless a host explicitly accepts a bounded motion contract and a reduced-motion fallback.
