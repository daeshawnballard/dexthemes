# DexThemes indexable page concepts

This is an isolated, implementation-backed visual prototype for the proposed
SEO/AEO page system. It does not register production routes, modify the current
DexThemes application, touch catalog or import contracts, or ship structured
data.

The prototype includes:

- The current app shell with a bottom-left Explore section
- An in-app Chat preview / Theme details view switch
- Contextual sharing inside Theme details
- Guide and collection hub pages
- One representative theme landing page: GitHub Dark
- How to install a Codex theme
- Create a custom Codex theme
- Codex theme import troubleshooting
- Dark themes
- Light themes
- Editor classics
- Community themes

Serve the repository root and open:

`/product-concepts/dexthemes-indexable-pages-2026-07-29/`

Use the concept navigation bar to switch among the primary views.

Start with **App shell**. Its bottom-left Explore links open the guide and
collection hubs, while the main header switches between the faux Codex chat
preview and a scrollable theme-details view. The public page concepts remain
separate because those server-rendered URLs would serve search and social entry
while the in-app details view serves product exploration.
